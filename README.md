# Hiragana Handwriting Classifier 

This project is a neural network-based Hiragana character recognizer. It allows you to draw Japanese Hiragana characters on a Tkinter canvas and predicts the character using a trained TensorFlow model.

## 🧠 Overview

- Built with: `Python`, `TensorFlow`, `Keras`, `Tkinter`, `Pillow (PIL)`
- Model type: Dense neural network (Multilayer Perceptron)
- Input: Handwritten Hiragana drawn on canvas
- Output: Predicted Hiragana character label
